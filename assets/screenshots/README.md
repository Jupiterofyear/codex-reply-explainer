# Screenshot source and editing

real-app-side-by-side.png and real-app-floating-overlay.png were edited from two real complete desktop screenshots supplied by the project owner. They show the side-by-side arrangement and the floating window overlapping the application, respectively. Chat and project titles and avatar initials were replaced, and a private attachment thumbnail was removed. Codex's built-in ImageGen tool performed the edits; this is an edited demonstration image rather than an untouched capture.

The fictional note-tool scenario was actually submitted to gpt-6.1-sol in an isolated local backend. Its 708-character reply was followed by a temporary fork using the plugin's unchanged explanation prompt, producing a 168-character explanation. The screenshot displays the latter portion of the original reply and the complete explanation. example-content.json contains both full texts. The illustration makes no claim that the fictional note tool was built or tested.

The temporary backend, saved example conversation, and authentication copy were removed after generation. No existing user chat, installed plugin, or desktop source was changed. Original private screenshots are not included in the repository or release archives.

The original image-editing output is included as PNG without enlargement or JPEG conversion. Its content-provenance metadata is retained; no embedded source screenshot or known private text markers were found in that metadata.

The window title in this real capture is 简短解释. The public package display name is Codex 回复解释. Existing interface controls and the explanation workflow have the same roles.
